## 📱 주요 기능
1. **실시간 GPS 거리순 정렬 & 숙소 기준 토글**
   - HTML5 Geolocation API 기반 내 위치 기준 실시간 거리 계산
   - GPS 미연동 시 베이스캠프(호텔) 기준 자동 정렬
2. **구글맵 다이렉트 1초 길찾기**
   - 각 매장 및 스팟별 구글맵 길찾기 링크 연동
3. **오프라인 대응 LocalStorage 북마크 & 체크리스트**
   - 네트워크 연결이 불안정한 해외 로밍 환경에서도 저장 데이터 영구 보존
4. **쇼핑 타겟 위시리스트 & 원스톱 꿀조합**
   - 쇼토쿠 우스하리 맥주잔 (다이마루 8F 등)
   - 몽벨 (로건부츠, 클리마플러스 모자, 샤미스 머플러)
   - 노스페이스 (키즈 눕시 부티 VII, 신발 특화 매장 등)
   - 원스톱 추천 동선: 그랜드 프론트 오사카 남관 5층 (몽벨 + 노스페이스 동일 층), 다이마루 & 파르코 3층 연결통로
5. **실전 일본어 회화 카드 & 백화점 5% 할인쿠폰 가이드**
   - 우스하리 잔 완충재(에어캡) 포장 요청 문구
   - 백화점 외국인 5% 할인쿠폰 발급 요청 문구
   - 160 사이즈 재고 문의 문구
